# 真人出镜封面（human-style）

适用于口播、剧情、测评、探店、生活记录、情绪共鸣类视频。核心是「一张有情绪张力的脸 + 强视觉焦点 + 醒目标题」。

## 适用场景模板

### 1. 口播 / 知识类
- 人物：单人，中景或近景，直视镜头。
- 表情：惊讶、认真、笃定、挑眉（按内容情绪选）。
- 环境：干净棚拍背景、书房、纯色墙面、演播室。
- 提示词骨架：
  ```
  真人女性/男性，[年龄感]，[发型+服装]，近景半身像，直视镜头，[表情]，背景[环境]，棚拍柔光/自然光，面部清晰锐利，皮肤真实有质感，电影感色调，画面右上角大字“标题文字”带白色描边
  ```

### 2. 剧情 / 反转类
- 人物：单人或多人都可，捕捉情绪高点瞬间。
- 表情：震惊、崩溃、狂喜、愤怒（戏剧化）。
- 环境：生活场景（客厅/办公室/街头），浅景深。
- 提示词骨架：
  ```
  真人[人物特征]，抓拍瞬间，[强烈表情]，动作夸张定格，背景[场景]虚化，情绪张力拉满，高对比电影打光，画面下方大字“标题文字”带深色遮罩条
  ```

### 3. 测评 / 开箱类
- 人物：手持产品，展示手势，视线看镜头或看产品。
- 环境：桌面布景、工作台，产品清晰可见。
- 提示词骨架：
  ```
  真人[人物特征]，近景，双手持[产品]展示，[表情]，背景[桌面/置景]虚化，产品与脸部同样清晰，顶光+侧补光，画面上方大字“标题文字”
  ```

### 4. 探店 / 生活 / 旅行类
- 人物：全身或半身，融入环境，自然抓拍感。
- 表情：享受、惊喜、放松。
- 环境：真实场景（餐厅/街道/景点），氛围光。
- 提示词骨架：
  ```
  真人[人物特征]，半身，站在[场景]中，回头/侧身看向镜头，[表情]，自然抓拍感，真实环境光，色调温暖，画面中部大字“标题文字”
  ```

### 5. 情绪价值 / 鸡汤励志类
- 人物：眼神有故事感，侧光或逆光，剪影轮廓。
- 表情：平静、坚定、落寞。
- 环境：逆光窗户、夜晚街头、空旷场景。
- 提示词骨架：
  ```
  真人[人物特征]，近景特写，逆光轮廓，[表情]，眼神有戏，背景[氛围场景]光斑虚化，情绪氛围感强，电影质感，画面中上大字“标题文字”
  ```

### 6. 人物 + 产品展示类（带货、新品推介、开箱）
- 人物：居中或一侧，摊手/比划/指向产品，表情自然带笑意或惊喜。
- 环境：产品实景，人物与产品同框，双产品可左右各放一台。
- 提示词骨架：
  ```
  真人[人物特征]，居中站立，双手摊开做展示姿态，[表情]，左右两侧各摆放[产品A][产品B]，画面上方大号标题“标题文字”，下方大号副标题“副标题”，深色背景，产品与人物同样清晰，商业摄影光
  ```

### 7. 人物 + 科技元素科普类（知识、揭秘、测评）
- 人物：手指向重点元素（屏幕/模型/实物），表情惊讶或笃定。
- 环境：深色背景 + 装饰线条/边框，右上角可加英文标识，标题置顶 1–2 行，常用黄/白大字搭配。
- 提示词骨架：
  ```
  真人[人物特征]，手指向[科技元素]，[惊讶/笃定表情]，深色[颜色]背景带红色装饰线条边框，画面上方黄色+白色大号标题“标题文字”，右上角英文标识[标识]，科幻氛围光，清晰锐利
  ```

## 竖屏封面（3:4）排版要点

1. 标题优先置顶：上 1/4 区域放 1–2 行大字，黄/白配色最醒目。
2. 人物居中偏下作视觉主体，视线或手指引导向画面重点。
3. 可用竖排文字作左侧装饰（沿画面左侧上下通排）。
4. 右上角可放小号英文品牌标识。
5. 深色底 + 高对比装饰线（红/黄）是数码科技类常用方案。

## 人物描述要素

- 性别 / 年龄感 / 体型
- 发型、发色
- 服装（颜色+款式+材质）
- 表情（惊讶/大笑/严肃/愤怒/震惊/笃定…）
- 视线（直视镜头 / 看产品 / 看向侧方）
- 手势动作（比手势、扶额、握拳、摊手…）

## 画面质感要素

- 打光：棚拍柔光、自然窗光、霓虹、逆光、高对比电影光
- 镜头：特写 / 近景 / 中景 / 半身
- 质感：真实皮肤纹理、相机质感（可指定设备效果，如 iPhone 拍摄的随手拍感、单反虚化感）
- 色调：暖调、冷调、胶片、高饱和

## 硬规则

1. 人物面部是视觉中心，禁止被标题文字大面积遮挡；标题避开面部。
2. 表情必须具体，禁止写“有表情”这类空泛词。
3. 可一次生成多张不同表情/构图备选，让用户挑。
4. 真实感优先：避免塑料感、过度磨皮，写“皮肤自然真实”。
