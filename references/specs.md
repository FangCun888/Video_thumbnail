# 规格速查（specs）

封面生成前先查此表，比例是硬约束。

## 统一比例规则（强制）

本 Skill 的封面比例固定为两种，不随平台变化：

- **竖屏封面：统一 3:4**（像素参考 1080×1440 或 1200×1600）
- **横屏封面：统一 4:3**（像素参考 1440×1080 或 1200×900）

无论用户提到抖音/B站/小红书/视频号等任何平台，竖版封面一律 3:4、横版封面一律 4:3，不做平台原生比例适配。宽高比不得超过 3:4 或 4:3。

## 横竖判断

- 用户指明横版/竖版 → 按对应统一比例。
- 未指定时默认竖屏 3:4。

## 文字安全区

- 四边各留出约 10%–15% 的净空，人物脸部和标题文字不得贴边。
- 竖屏 3:4：主标题优先放在画面中上部（约 25%–45% 高度区间），底部留白给进度条/UI。
- 横屏 4:3：主标题居中偏左或居中偏右，避免中心遮挡主体关键部位。

## 标题字数规范

- 主标题：8–12 字以内，字号大、笔画粗、高对比，缩略图（如 200px 宽）下仍清晰可读。
- 副标题：不超过 15 字，字号小于主标题，颜色/透明度与主标题区分。
- 单图文字块不超过 3 组（主标题 + 副标题 + 角标/卖点）。

## 避坑清单

1. 文字错字、漏字、变形 → 生成后用肉眼核对每一处文字。
2. 画幅不符 → 修改提示词前先确认比例参数，禁止后期硬裁。
3. 主体被边缘裁切 → 提示词中写明主体居中或留边距。
4. 文字被背景吞没 → 要求文字加描边/投影/深色遮罩层，或选高对比背景。
5. 小尺寸糊 → 避免细字、细线、低对比配色，多用纯色大色块。
6. 真人封面面部模糊 → 明确“面部清晰、对焦准确”。
