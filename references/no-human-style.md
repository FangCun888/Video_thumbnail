# 无人出镜封面（no-human-style）

适用于不想露脸的内容：干货知识、产品推广、新闻资讯、影剧剪辑、课程推广等。核心是「大字标题 + 高对比构图 + 清晰视觉焦点」，不出现真人。

## 适用场景模板

### 1. 大字报 / 纯文字排版类
- 用途：干货、观点、清单、资讯。
- 构图：纯色或渐变背景，超大主标题居中/偏上，副标题或卖点小字在下方，可加粗体强调。
- 提示词骨架：
  ```
  极简大字报风格封面，纯[颜色]渐变背景，中央超大号粗体白字“标题文字”，下方小字副标题“副标题”，文字加黑色描边，四周留白，扁平设计，高对比
  ```

### 2. 产品展示类
- 用途：带货、开箱、新品。
- 构图：产品居中或 3/4 视角，光影质感，标题在上下留白区，可加卖点角标。
- 提示词骨架：
  ```
  电商感产品封面，[产品描述]置于画面中央偏下，顶部超大标题“标题文字”，底部副标题“卖点”，产品带真实阴影和倒影，背景[颜色]渐变，柔和棚拍光，商业摄影质感，高清晰度
  ```

### 3. 场景氛围类
- 用途：旅行、美食、家居、风景。
- 构图：大场景图铺满，标题压在画面下方 1/3，深色渐变遮罩保证文字可读。
- 提示词骨架：
  ```
  [场景描述]高清摄影图铺满画面，画面下方叠加深色渐变遮罩，遮罩上白色大字“标题文字”，上方角落小字副标题，真实感光影，色彩浓郁
  ```

### 4. 图形 / 3D 插画类
- 用途：教程、动画、科普、游戏。
- 构图：3D 元素或插画主体 + 几何背景，标题居上或居中。
- 提示词骨架：
  ```
  3D 立体插画风格封面，[主体元素]，彩色渐变背景，主体置于画面中下，上方大字标题“标题文字”，粗描边，圆润造型，明亮活泼，皮克斯质感
  ```

### 6. 左文右图 / 图文并茂类（软件教程、选购指南、数码科技）
- 用途：软件安装教程、数码选购指南、科技资讯、产品评测。
- 构图：左侧 40%–50% 放标题文字区（主标题 2–4 行大字 + 副标题/卖点），右侧放产品截图或界面展示；可加品牌角标（简称+全称）于左下角。
- 提示词骨架：
  ```
  软件宣传封面，统一[深色/浅色]科技风背景，左侧大字标题“标题文字”，[副标题]小字，右侧展示[软件界面/产品图]，左下角品牌角标[简称+全称]，高对比，干净留白
  ```

### 7. 图标阵列 + 大字标题类
- 用途：软件套件、多产品/多品牌合集、版本升级教程。
- 构图：左侧并排 2–3 个产品立体图标，右侧大号标题（分 2–3 行），背景带装饰线条/光效。
- 提示词骨架：
  ```
  产品合集封面，[颜色]背景带金色装饰线条，左侧并排[产品1][产品2][产品3]立体图标，右侧金色/白色立体大字标题“标题文字”分[2-3]行，光影炫酷，商业质感
  ```

### 8. 产品阵列 + 卖点标签类
- 用途：多产品推荐、月度榜单、测评合集。
- 构图：左侧标题区（主标题 + 品牌/型号列表 + 下方并排卖点标签），右侧产品图阵列。
- 提示词骨架：
  ```
  推荐榜单封面，[颜色]科技风背景，左侧上方大字标题“标题文字”，下方品牌列表[品牌A｜品牌B｜品牌C]，底部三个卖点标签“卖点1”“卖点2”“卖点3”，右侧[多款产品]排列展示，布局整齐，专业感
  ```

### 9. LOGO 立体化海报类（APP 推广、会员权益、新品发布）
- 用途：APP 推广、会员权益宣传、新品发布、软件介绍。
- 构图：LOGO 以立体卡片/3D 质感置于画面一侧，配品牌色光效背景；另一侧大标题 + 卖点按钮。
- 提示词骨架：
  ```
  [品牌色]浅色渐变背景配流动光效曲线、光斑与[水珠/声波]等氛围元素，左侧[APP LOGO]以立体卡片形式呈现：白色方形卡片+品牌色立体字母，带厚度、高光与柔和投影；右侧大号标题“标题文字”分[2-3]行，下方[卖点]按钮样式文字；整体科技动感，保持LOGO图形与品牌色准确
  ```
- 参考样例：`assets/references/landscape-no-human/11.jpeg`（浅蓝主色 + 立体 LOGO 卡片 + 光效背景）。

### 5. 对比 / 前后类
- 用途：教程前后对比、价格对比、改造对比。
- 构图：左右分屏或上下分屏，中间放箭头/VS 标识，标题在顶部。
- 提示词骨架：
  ```
  左右分屏对比封面，左图[改造前状态]，右图[改造后状态]，中间竖排大字“VS”，顶部横幅标题“标题文字”，深色背景，对比强烈，清晰分界
  ```

## 文字排版要素

- 主标题：超大字号、粗体、高对比色（白/黄/黑最常见）
- 副标题：小字，可加底色块或描边
- 角标：卖点、期数、价格等小标签，圆角矩形底
- 遮罩：深色渐变条（下 1/3 常用）保证文字可读

## 配色原则

- 标题色与背景色明度差要大（深底白字 / 浅底深字）
- 主色不超过 2–3 种，用纯色大色块
- 品牌场景优先用品牌色作背景

## 硬规则

1. 文字是主角：主标题必须最大、最醒目，禁止被图案元素压制。
2. 遮罩/描边至少保留一种，保证缩略图下可读。
3. 画面只保留一个视觉焦点（产品 or 场景 or 图形），不堆砌元素。
4. 产品图优先写“商业摄影质感、真实光影、高清”，避免廉价感。
