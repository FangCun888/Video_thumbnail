# Video_thumbnail — AI 视频封面生成 Skill

面向创作者的一站式视频封面生成 Skill，基于澄清式提问自动选择风格分支并生图。

## 功能特性

- **澄清式流程**：依次询问主题 → 人物图（真人/动漫）→ 产品图 / APP LOGO，按素材组合自动分支
- **风格分支**：
  - 有人物图 → 按人物图画风生成，保持形象一致
  - 有 APP LOGO → 以立体风格呈现（立体卡片 + 品牌色光效）
  - 无素材 → 自动生成无人风格封面（大字报 / 科技左文右图 / 产品阵列等 9 种模板）
- **统一规格**：竖屏一律 3:4，横屏一律 4:3
- **参考图库**：内置 21 张横屏无人 / 竖屏人物风格样例

## 使用流程

1. 告诉我封面大致主题
2. 有没有人物图？（真人 / 动漫都可以）
3. 有没有产品图或 APP LOGO？
4. 按组合自动生成封面
